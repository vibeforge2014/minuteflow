修复 20+ 缺陷，分 6 批按风险推进。每批改完即跑 `npm run typecheck && npm run build` 验证。三个方向性决策已确认：时间戳改为相对录音起点 00:00:00；授权时钟回拨用单调时间+文件 mtime 双校验；macOS 加 entitlements 文件。

## 第一批：录音数据安全（P0，最高优先）

### 1.1 修复 writeQueue 一次失败永久损坏会话 — `electron/main.mjs:269-293`
当前 `record.writeQueue = record.writeQueue.then(async ()=>{...})` 链式 Promise，一次 reject 后整个链永久 rejected，后续所有 append 都失败、音频静默丢失。

**改法**：每个 append 不再无脑续链，而是捕获自身错误后**恢复队列**为 resolved，避免毒化下游；把错误单独累积到 `record.lastError`，stop 时据此判断是否成功。
```
record.writeQueue = record.writeQueue
  .catch(() => {})              // 吞掉上游错误，恢复链为 resolved
  .then(async () => { /* 写盘逻辑，出错时 record.lastError ??= error */ });
```
append 的 catch 不再向渲染层抛（避免渲染层吞掉后继续喂 chunk 也无意义），而是记录到 `record.lastError` 并在 stop 阶段统一处理。

### 1.2 修复 recordings:stop 把损坏文件标记为 complete — `electron/main.mjs:295-334`
当前即使 writeQueue reject，仍 stat→只要 size>0 就 rename→finalizeAudioPath→存 complete，`writeError` 直到最后才抛（且 return output 已被 throw 覆盖）。

**改法**：
- 每轨 drain 后检查 `record.lastError`；若该轨有错，**不 rename**（保留 .partial 供诊断）、不 finalize、记录到 `output[track] = null` + 收集错误。
- meeting 状态：全部成功 → `complete`；任一轨出错 → `interrupted`（不是 complete），并把错误写进 `meeting.notes` 让用户可见。
- 只在无 writeError 时 return output；有错时仍 throw（带聚合错误），但在此之前已把 meeting 存为 interrupted，保证不丢"未完成"信号。

### 1.3 修复 before-quit 不被 await — `electron/main.mjs:658-664`
`app.on("before-quit", async ()=>{...})` 的 promise Electron 不等待。

**改法**：用 `event.preventDefault()` + 串行刷盘 + `app.exit()`：
```
let isQuitting = false;
app.on("before-quit", (event) => {
  if (isQuitting || recordingFiles.size === 0) return;
  event.preventDefault();
  isQuitting = true;
  (async () => {
    for (const record of recordingFiles.values()) {
      record.closing = true;
      await record.writeQueue.catch(() => {});
      await record.handle.close().catch(() => {});
    }
    recordingFiles.clear();
    app.exit();
  })();
});
```
同时给渲染层加 `beforeunload`：`src/App.tsx` 的 useEffect 里注册 `window.addEventListener("beforeunload", ...)`，若正在录音则 `event.preventDefault()` + 提示，并调用 `recorder.stop()`。配合 `close` 事件兜底。

### 1.4 mini 模式交通灯避让 — `electron/main.mjs:617-630`
进入 mini(420×104) 时未调整 darwin padding。给 mini 模式的渲染层根元素加 `body.is-mini .brand { padding-left: 72px }` 已有 darwin 规则复用；确认 mini 视图内交互元素 y 坐标避开 0–32px 灯区（现有 mini UI 若紧凑布局需下移）。

**验证**：改完手动跑 `npm run build`，确认无类型错误。第一批不引入新依赖。

## 第三批：授权加固（P1）

### 3.1 时钟回拨防御：单调时间 + mtime 双校验 — `electron/services/licensing.mjs`
- 引入 `import { monitor } from "node:perf_hooks"` 不够（进程重启归零），改用 **process.uptime() 累积 + license.json 的 mtime 作墙钟参照**：
  - state 新增 `lastVerifiedUptimeMs`（写入时 `process.uptime()`）和保留 `lastVerifiedAt`。
  - 校验时：若 `Date.now() < lastVerifiedAt 时间戳`（墙钟倒退）**或** `now - lastVerifiedAt` 声称过了 N 小时但 `process.uptime()` 增量远小于 N（墙钟被拨慢）→ 判定异常，强制联网刷新（refresh=true），失败则进 error 而非宽限。
  - 用 `fs.stat(license.json).mtime` 作为 lastVerifiedAt 的旁路证据：若文件 mtime 显示距现在远小于 lastVerifiedAt 声称的时长，说明时钟被回拨。
- 离线宽限仍按 lastVerifiedAt 算，但进入宽限前先做回拨检测；检测到回拨直接判 error。

### 3.2 设备指纹 — `licensing.mjs:45-50, ensureDeviceId`
`deviceId` 当前是随机 UUID 存明文，复制即绕过。**改法**：deviceId = `randomUUID` + 机器特征哈希（macOS: `ioreg` 序列号 / hostname + CPU 型号 + MAC 地址的稳定子集），合成"逻辑 deviceId（随机）+ 机器指纹"二元组。验证请求带上机器指纹；`ensureDeviceId` 每次校验机器指纹是否与 state 中记录一致，不一致 → 判 error（提示"授权已绑定其他设备"）。

> 取指纹用纯 Node（`os.hostname()`、`os.networkInterfaces()` MAC、`os.cpus()`），避免加 native 依赖。

### 3.3 safeStorage 不可用时降级 — `electron/services/secrets.mjs:27` + `licensing.mjs:135`
当前未签名构建 safeStorage 不可用 → 激活在**服务端验证通过后**抛错，付费用户被锁出。

**改法**：
- `storeSecret`：safeStorage 不可用时，**回退到明文存 secrets.json**（仍 0o600）并返回 id，不抛错；但 `readSecret` 增加"是否明文"标记，`licensing.mjs` 在 publicStatus 里暴露 `insecureStorage: true` 让 UI 可提示"当前为未签名版本，密钥未加密存储"。
- 关键：`activateLicense` 调整顺序——**先 storeSecret 再 writeState**（当前已是该顺序，问题在 storeSecret 抛错）；改后 storeSecret 不抛，writeState 正常落地。
- `getLicenseStatus:104-108`：readSecret 返回空时**不要** `writeState({deviceId})` 清空整个授权状态，改为保留 state 只标记 secretMissing，返回 error 提示"密钥库锁定，请重启或重新激活"。

### 3.4 429/5xx 不应触发离线宽限 — `licensing.mjs:88-90,120-123`
当前任何非 2xx（含 429/5xx）都当网络故障走 30 天宽限。

**改法**：`verifyRemotely` 区分——401/403/410 = 授权明确无效，抛 `LICENSE_INVALID`（终止宽限）；429/5xx/网络错误 = 暂时不可达，抛 `LICENSE_TRANSIENT`（可走宽限）。宽限分支只接 TRANSIENT。

**验证**：typecheck + build。

## 第四批：macOS 体验（P1）

### 4.1 系统音频引导 — `electron/main.mjs:180-194` + `SystemPermissionsDialog.tsx`
Mac 用 `useSystemPicker:true`，音频 loopback 仅 win32 生效；用户不知要勾"共享电脑音频" → 远端参会者无声。

**改法**：
- `system:get-permissions` 返回 `systemAudioPickerHint: true`（macOS 标记）。
- `SystemPermissionsDialog.tsx` 的系统音频行在 macOS 显示引导文案："选择屏幕时请在系统弹窗中勾选'共享电脑音频'，否则仅录制本地麦克风"。
- 权限墙增加"了解 Mac 系统音频"展开说明。

### 4.2 系统设置深链修正 — `main.mjs:611-613`
`x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture` 在 macOS 13+ 失效。

**改法**：macOS 14+ 用 `x-apple.systempreferences:com.apple.settings.preference.privacy`（统一新 scheme）；按 `process.getSystemVersion()` 区分。保留旧 scheme 给 14 以下（min 14.2，实际新 scheme 即可，但加 fallback）。

### 4.3 唤醒后摘要计时器恢复 — `src/hooks/useMeetingRecorder.ts:199-208`
`system:resume` 只弹提示，**从不重启 summaryTimerRef** → 合盖一次后滚动纪要静默失效。

**改法**：resume 回调里，若 `recorderRef.current` 仍存在且 phase 应为 recording，重启 `summaryTimerRef`（clearInterval 后 setInterval），并 `recorderRef.current.resume()`（当前只 setWarning）。注意保留"请检查设备"提示但自动恢复运行，而非要求用户手动点（用户可能已离开）。

### 4.4 start 失败时清 summaryTimer — `useMeetingRecorder.ts:118-128`
`summaryTimerRef` 在 start 成功路径设置，若 `recorder.start()` 抛错，catch 未清该 timer → 幻影摘要生成。catch 分支加 `if (summaryTimerRef.current) clearInterval`。

**验证**：build + 手动确认。

## 第五批：笔记/编辑器 UI（P2，已核实）

### 5.1 列表 key 导致每键丢焦点 — `DocumentWorkspace.tsx:222,317-320`
keyPoints/decisions/openQuestions/risks/nextSteps 用 `key={item-index}`，item 是被编辑文本，打字即 key 变 → 卸载重建失焦。

**改法**：给每个列表项分配稳定 id。`Meeting.summary` 的这些 string[] 改为 `{id, text}[]`？改动大。**更轻量方案**：用 `useRef` 为每行维护一个稳定 key 池（基于 index 位置而非内容）：`key={`kp-${index}`}`（去掉 item），编辑时 index 不变即可保稳定。因这些列表是固定顺序、按 index 编辑，用 index 做 key 是安全的（React 警告只针对重排/插入场景；这里增删走 setSummaryList 整体替换，index 稳定）。
- keyPoints: `key={kp-${index}}`
- 4 个 EditableSummaryList 同理传 index 作 key。
- 行动项已用 `item.id`，不动。

### 5.2 转写时间戳 +10h 丢秒 — `TranscriptPanel.tsx:213-216`
改为相对录音起点 `00:00:00`，含秒：
```
function formatTranscriptTime(ms) {
  const total = Math.floor(ms / 1000);
  const h = Math.floor(total/3600), m = Math.floor((total%3600)/60), s = total%60;
  return `${pad(h)}:${pad(m)}:${pad(s)}`;  // 或短会议省略 h
}
```
（已确认数据里有 startMs 相对录音开始。）

### 5.3 纪要时间戳硬编码 10:MM — `DocumentWorkspace.tsx:474`
当前 `formatSummaryTime(index)` 返回 `10:${index*2}`。改为相对录音起点的近似时间。但 summary keyPoints 无 startMs 字段。**改法**：显示"第 N 条"或基于 index 估算 `00:0X`（去掉假的 10）。更稳妥：keyPoints 若有 `atMs` 字段则用，否则省略时间戳只显示条目。本轮先改为 `00:${pad(index*2)}` 去掉 10h 假象，并加注释说明是占位。

### 5.4 "最终版"按钮无 onClick — `TranscriptPanel.tsx:71-74`
两个子标签"实时转写/最终版"无 handler。

**改法**：要么实现（filter `segment.status === "final"`），要么删除"最终版"避免死按钮。本轮**删除"最终版"**（实时转写本就含 final 与 partial，分离价值低，且无设计稿支撑该切换），保留单标签。

### 5.5 EditableList 追加行每键累加 — `DocumentWorkspace.tsx:415-422`
`<input value="" onChange={if(v) onChange([...values,v])}>` 每键追加。

**改法**：改为本地受控 state（`useState("")`），onChange 只更新本地值，`onKeyDown Enter` 或失焦时才 append 并清空。

### 5.6 Markdown 导入 BOM + 大小限制 — `DocumentWorkspace.tsx:70-82` + `main.mjs:430-441`
- 导入时 `.replace(/^\uFEFF/, "")` 去掉 BOM。
- main 的 `notes:import-markdown` 加文件大小上限（如 5MB），超限抛"文件过大"。

**验证**：build + 浏览器手测编辑器打字不丢焦。

## 第六批：健壮性（P3）

### 6.1 DB 写串行化 — `electron/database.mjs`
单连接共享 + 录音/摘要并发 → `cannot start a transaction within a transaction`。

**改法**：包装一个写互斥锁（Promise 队列）`withWriteLock(fn)`，`saveMeeting`/`appendAudioChunk`/`finalizeAudioPath`/`softDelete` 等所有写操作走锁。同时 `PRAGMA busy_timeout = 5000`。读不受锁（WAL 允许并发读）。

### 6.2 FTS5 与会议保存隔离 — `database.mjs:246-258,325`
当前 `indexMeeting` 在 persistMeeting 的外层事务里，FTS 损坏会回滚真实数据。

**改法**：`persistMeeting` 先在主事务完成 meetings+segments 写入并 COMMIT，**再**单独 try/catch 调 `indexMeeting`（独立小事务）；FTS 失败只 log，不回滚主数据。启动时 `INSERT INTO meeting_search(meeting_search) VALUES('rebuild')` 做 integrity check（包 try/catch）。

### 6.3 模型测试真实 spawn — `providers.mjs:340-345,355-364`
whisper-cpp/sherpa 的 test 只查路径非空。

**改法**：实际 spawn `${executablePath} --help` 或 `-h`（whisper-cli 支持），5s 超时，exit 0 或输出含已知字样即 ok。失败返回 `{ok:false, message}`。

### 6.4 macOS entitlements 文件 — 新增 `entitlements.mac.plist` + `forge.config.mjs`
新增：
```
com.apple.security.cs.disable-library-validation = true  （加载 whisper.cpp/.node）
com.apple.security.device.audio-input = true
com.apple.security.cs.allow-jit = true （whisper.cpp 可能需）
```
forge.config.mjs 的 osxSign 引用该 plist；ad-hoc 分支保留但注释说明仅开发用。加 `LSMinimumSystemVersion: 14.2` 到 extendInfo。修正 bundle id 一致性（licensing productId vs appBundleId，本轮以 forge 的 `com.meetingassistant.desktop` 为准，licensing.mjs 的 productId 改为同值——但 productId 是发给验证服务的业务标识，改它需服务端配合；本轮**保留 licensing productId 不变**，在注释说明二者用途不同，不算 bug）。

### 6.5 下载进度限速 — `electron/services/local-models.mjs:207` + `main.mjs:427`
按时间节流（每 250ms 至多发一次 progress），并在 `event.sender.send` 前判 `event.sender.isDestroyed()`。并发下载去重（`Map<modelId, Promise>`）。

### 6.6 secrets 原子写 — `electron/services/secrets.mjs:18-35`
改用 tmp + rename（与 licensing.mjs 一致）；加简单写锁防并发覆盖。

### 6.7 杂项
- `main.mjs:235` `mainWindow?.webContents.send` 加 `webContents.isDestroyed()` 判断。
- `updates.mjs:186` `compareVersions` 对非 semver `app.getVersion()` 防御（try/catch 降级为"无法比较"）。
- `providers.mjs:213-226` `runProcess` 加超时（whisper 10min）+ maxBuffer。
