# 桌面端完善：修复确认的功能缺陷 + 清理重复代码

## 范围
针对 `src/` 桌面渲染层确认存在的功能性缺陷和明显的重复代码进行收尾完善。所有改动行为保持向后兼容，不改变产品视觉系统或信息架构。

## 改动清单

### 1. 新建 `src/lib/format.ts`（格式化工具，消除重复）
- 导出 `formatDuration(seconds)`：条件式 `MM:SS`（小时为 0）或 `HH:MM:SS`（≥1 小时）——即 `TranscriptPanel.formatTranscriptTime` 现有形态，最通用。
- 导出 `formatInterval(seconds)`：`X 分钟` / `X 秒`。
- 替换 4 处 `MM:SS` 重复定义：`Sidebar.tsx`、`DocumentWorkspace.tsx`、`RecorderBar.tsx`、`useMeetingRecorder.ts`。
- 保留 `App.tsx` 内的固定宽 `HH:MM:SS`（用于「重点标记」日志式时间戳，刻意保持 3 段），仅作单点使用。
- `formatTranscriptTime` / `formatDate` / `formatMeetingDate` 仅单处使用，留在原文件，不过度搬迁。

### 2. `src/components/Sidebar.tsx` — 修复日期漂移（真实 Bug）
- `groupMeetings` 的 `anchor` 从硬编码 `new Date("2026-07-30T12:00:00+08:00")` 改为 `Date.now()`。
- `groupMeetings` 已被 `useMemo([meetings])` 包裹，会议列表变化时重新计算；会话期间漂移可忽略。
- 改用共享 `formatDuration`。

### 3. `src/components/TranscriptPanel.tsx` — 接线自动滚动（真实 Bug）
- 新增 `autoScroll` 受控状态（默认 `true`）+ `listRef`。
- `<input>` 改为 `checked={autoScroll} onChange={...}`。
- 新增 `useEffect`，依赖 `meeting.transcript.length` 与 `meeting.id`：当 `autoScroll` 为真 **且** 用户处于接近底部位置（`scrollHeight - scrollTop - clientHeight < 80px`）时，滚动到底部；用户上滑阅读时不强制拉回（标准「贴底」模式）。
- 从 props 接口移除未使用的 `onAppend`，并相应清理 `App.tsx` 的传递与 `useMeetingStore` 的 `appendTranscript` 仅在该处消费的引用（确认 `useMeetingRecorder` 仍直接从 store 读取，不受影响）。

### 4. `src/components/DocumentWorkspace.tsx` — 修复伪造时间戳与死按钮（真实 Bug）
- **伪造时间戳**：`formatSummaryTime(index)` 返回虚假 `00:MM`。`MeetingSummary.keyPoints` 仅为字符串数组，无时间元数据。改为在 `<time>` 槽位渲染诚实的序号标记（`{index + 1}`），保留时间轴左轨视觉，但内容真实。删除 `formatSummaryTime` 函数与误导性注释。
- **死按钮**：「查看全部纪要（N 条）」无 `onClick`，且时间轴已展示全部要点（CSS 无折叠）。移除该按钮与 `keyPoints.length > 4` 守卫，保留「is-new」高亮（最近 3 条）作为新进度指示——最小、诚实、不引入新的折叠状态。
- 改用共享 `formatDuration` / `formatInterval`。

### 5. `src/lib/api.ts` — 版本号同步（清理）
- 浏览器更新检查 stub 的 `currentVersion: "0.1.1"` → `"0.1.2"`，与 `package.json` 对齐（仅影响浏览器预览的更新检查 stub，不影响 Electron 主进程的真实更新检查）。
