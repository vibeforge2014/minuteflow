## 描述

MinuteFlow 是一款本地优先的 AI 会议助手。说话的时候，纪要已经开始成形。

【核心能力】
• 会议录音：录制麦克风，支持暂停、继续与时间戳标记，音量反馈一目了然
• 实时转录：Apple Speech 边说边转文字，说话人标签可改名与重新分配
• 智能纪要：默认每两分钟增量整理，会议结束后生成最终纪要——议题、关键点、决策与行动项
• 模型自选：既可用系统语音识别，也可配置远程 Whisper 转写与 OpenAI 兼容纪要服务，API Key 只存 Keychain
• 导入转写：音频、视频文件导入后同样可转录并生成纪要
• 会议资料库：全文搜索、收藏、软删除与恢复
• 多格式导出：Markdown、TXT、SRT 与 JSON 备份
• iPad 三栏工作区：会议库、文档与纪要同屏协作；iPhone 自适应导航

【隐私设计】
• 会议内容默认保存在本机，不上传任何服务器
• 未配置远程模型时不发生网络传输；配置后仅向所选服务发送对应任务所需内容
• 录音只采集麦克风，不捕获其他 App 的受保护音频

支持中文与中英混合会议。
